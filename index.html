☁️ 두 사람 폰에서 같이 쓰기

Supabase 무료 프로젝트를 하나 만들고 URL과 anon key를 넣으면, 모과·생강 폰에서 같은 콘티가 실시간으로 맞춰져요. 넣지 않으면 이 폰에만 저장됩니다.

아직 연결하지 않았어요 · 이 폰에만 저장 중
Supabase 준비 방법 (5분)
  1. supabase.com 로그인 → New project 만들기
  2. 왼쪽 SQL Editor에 supabase_schema.sql 내용 붙여넣고 Run
  3. Project Settings → API에서 Project URL과 anon public 키를 복사
  4. 위 두 칸에 붙여넣고 연결하기 → 생강 폰에는 설정 코드를 복사해 보내면 끝

💾 백업 · 옮기기

콘티 전부를 JSON 파일로 내려받거나, 받은 파일을 그대로 불러올 수 있어요.
