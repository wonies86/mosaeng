# 모생일기 · 콘티 노트 📝

모과 & 생강의 인스타툰 **「모생일기」** 글콘티 메모장.
떠오른 썰을 제목 · 작성자 · 등장인물 · 카테고리 · 진행 상태 · **1~4컷 대사**로 적어두고, 그릴 때 바로 꺼내 쓰는 페이지입니다.

- 주소: https://wonies86.github.io/mosaeng/
- 모바일(390×844) 기준으로 만들었고 PC에서도 2열 카드로 넓게 보입니다.

## 등장인물 (모생 유니버스)

| 인물 | 관계 · 성향 | 한 줄 |
| --- | --- | --- |
| 모과 | 나 · E | 하이텐션 E, 먹방과 캠핑 진심 |
| 생강 | 남편 · I | 무덤덤 I, 조용한 팩트폭격기 |
| 자두 | 절친 · E | 모과와 만나면 텐션 2배 폭발하는 E 절친 |
| 대추 | 절친남편 · 선비 I | 조용하고 묵직한 선비형 I 남편 |
| 한라봉 | 예비초1 · 씩씩 | 자두 엄마한테 맨날 장난당하지만 밝고 씩씩하게 자라는 예비 초1 |
| 멜론 | 여동생 · 하이텐션 E | 모과 여동생, 시원시원한 하이텐션 E |
| 적포도 | 제부 · I | 조용하고 편안한 I 성향 제부, 청포도 아빠 |
| 능금 | 첫째 · 초5 | 차분하고 다정한 초5 |
| 청포도 | 둘째 · 초3 | 뛰어다니기 좋아하는 우당탕탕 초3 |
| 콩이 | 반려견 · 막내 | 동글동글 곰돌이컷 포메라니안, 애교 만점 막내 (모과 반려견, 지금은 본가에서 모과 어머님이 케어 중) |

목록 상단 **등장인물** 바에서 인물을 누르면 인물 카드(프로필)가 열리고, **이 인물 콘티 모아보기**로 그 인물이 나오는 편만 모아볼 수 있습니다.

## 🎬 릴스 · 🏷️ 해시태그 (조회수용 도구)

목록 위 **🎬 릴스 만들기 / 🏷️ 해시태그 5개** 버튼, 또는 에피소드 상세의 **🎬 이 편으로 릴스 만들기 / 🏷️ 황금 해시태그 5개** 블록에서 열 수 있습니다.

1. **릴스**: 컷 이미지 1~9장 선택(파일명 순서로 들어가고 ▲▼로 조정) → 비율(9:16 추천 / 1:1) → 컷당 시간(1.5·1.8·2.2초) → 전환(페이드 / 바로) → **영상 만들기**. 렌더링은 전부 폰 안에서 일어나고(서버 업로드 없음), 진행률이 100%가 되면 미리보기와 **📥 영상 저장**이 나타납니다. 안드로이드 크롬은 MP4, 지원하지 않는 브라우저는 WebM으로 저장됩니다.
2. **해시태그**: 카테고리·제목·태그·등장인물을 읽어 대형 일상툰 태그 2개 + 주제 맞춤 2개 + `#모생일기` 1개, 총 **5개**만 만듭니다. `🔄 다른 5개`로 조합을 바꾸고 **📋 5개 복사**로 인스타 캡션에 붙여넣으면 됩니다.
3. **스레드 문구**: `🧵 스레드 맛보기 문구`를 복사해 스레드에 올리면 인스타 `@mosaeng.toon`으로 유입됩니다. 문구는 직접 고쳐도 됩니다.

## 두 사람 폰에서 같이 쓰기 (Supabase, 무료)

1. https://supabase.com 에서 **New project** 하나 만들기 (무료 플랜으로 충분)
2. 왼쪽 **SQL Editor** → [`supabase_schema.sql`](supabase_schema.sql) 내용을 붙여넣고 **Run**
3. **Project Settings → API** 에서 **Project URL** 과 **anon public** 키 복사
4. 앱 오른쪽 위 **⚙️ → 두 사람 폰에서 같이 쓰기** 에 두 값을 붙여넣고 **연결하기**
5. 상대 폰에서는 **설정 코드 복사** 로 코드를 보내고, 그 폰에서 **코드로 불러오기** → 끝

> anon key는 두 사람만 공유하세요. 테이블이 anon에게 열려 있어서 키를 아는 사람은 콘티를 볼 수 있습니다. (개인 메모장 용도)
